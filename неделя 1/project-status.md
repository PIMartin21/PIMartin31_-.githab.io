# Исходное состояние проекта SmartWardrobe

## 1. Состояние технического задания

Техническое задание повторно проверено. По результатам проверки
внесены следующие изменения:

### 1.1. Хранение фотографий

- **Было:** хранение фото в Google Drive.
- **Изменено на:** хранение фото в локальной файловой системе
  устройства (папка приложения). В базе данных SQLite хранится
  только путь к файлу фотографии.

### 1.2. Подбор образов

- **Было:** генерация образа по событию (свидание, работа, спорт,
  прогулка); подбор сочетаний для вещи.
- **Изменено на:** подбор образа по погоде; показ вещей той же
  категории.

### 1.3. Напоминания о редко используемых вещах

- **Было:** напоминания о редко используемых вещах (push-уведомления).
- **Изменено на:** отображение списка «забытых» вещей
  (не использовались более 30 дней).

### 1.4. Требования к надёжности

- **Было:** время восстановления системы после сбоя — не более суток.
- **Изменено на:** при перезапуске приложения данные не теряются.

### 1.5. Прочие изменения

- исключено удалённое и еженедельное резервное копирование
  как избыточное для учебного проекта;
- исключено формирование списка покупок;
- исключён подбор сочетаний по цвету и стилю;

### 1.6. Что было добавлено

- **ER-диаграмма для схемы БД** — для визуального проектирования
  структуры базы данных (сущности Category, Item, Outfit, OutfitItem
  и связи между ними).
- **Локальное хранение фотографий в файловой системе устройства** —
  в базе данных SQLite хранится только путь к файлу. Это заменило
  облачное хранение через Google Drive.
- **Кэширование данных погоды на 24 часа** — для работы приложения
  без интернета. При отсутствии сети используются последние
  сохранённые данные о погоде.

## 2. Что уже подготовлено

- создан репозиторий проекта на GitHub;
- подготовлено техническое задание (актуальная версия);
- выбраны технологии: Flutter, SQLite, OpenWeatherMap;
- выбраны инструменты: VS Code, Figma, Github;

## 3. Что ещё не реализовано

- структура проекта Flutter;
- экраны приложения (Гардероб, Образы, Аналитика, Профиль);
- работа с SQLite;
- добавление и хранение фото;
- интеграция с OpenWeatherMap;
- алгоритм подбора образа по погоде;
- ручной подбор и сохранение образов;
- статистика (топ-3, забытые вещи);
- тёмная/светлая тема.

## 4. Ближайшие задачи

1. Разработка макетов в Figma.
2. Спроектировать и создать схему БД в SQLite.
3. Реализовать экран «Гардероб»: добавление вещи с фото,
   список вещей, фильтрация по категориям.
4. Реализовать редактирование и удаление вещи.
